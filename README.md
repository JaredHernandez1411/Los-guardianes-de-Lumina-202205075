# Los-guardianes-de-Lumina-202205075
Repositorio del videojuego "Guardianes de Lumina"

# Fase 1 Análisis del videojuego
Se realizo un análisis de como uno deseaba su videojuego, describiendo una breve historia de nuestro juego, algún elemento especial o movimientos que nuestro jugador puede realizar, así como la comunicación que podríamos tener y el como se haría visible, si nuestro modo seria multijugador o solitario y para que edad estaría disponible.

# fase 2 Diagrama de flujo
En esta fase realizamos un diagrama de nuestro videojuego, detallando las decisiones que debería o deberá tomar el jugador, así el cuantos niveles tendrá, que diferencia o similitudes de nuestros niveles tendrán entre sí, mensajes, puntaje, movimientos, ataques, si desea salir o reiniciar el nivel y si desea regresar al menú o salir del juego.

# Fase 3 Desarrollo de nuestro codigo
En esta fase realizamos o desarrollamos nuestro código, utilizando comandos esenciales o especificas para cada nivel, el menú principal y las decisiones basándonos en el diagrama de flujo de la fase 2, realizando multiples pruebas y verificando posibles errores o bucles que nuestro juego podria tener.

# Fase 4 GitHub
Después de realizar las primeras 3 fases de nuestro videojuego, iniciamos o creamos una cuenta en Github, donde subiremos los documentos necesarios y solicitados de nuestro videojuego, donde explicaremos las fases realizadas para realizar nuestro videojuego.
